# TryHackMe SOC Level 1

This repository documents my journey and experience completing the TryHackMe SOC Level 1 path: [https://tryhackme.com/path/outline/soclevel1](https://tryhackme.com/path/outline/soclevel1)

## Objectives

The SOC Level 1 path on TryHackMe covers essential skills for aspiring Security Operations Center analysts. Key objectives include:

* **Detect and analyze traffic anomalies:** Learn to identify suspicious network traffic using tools like Wireshark and Snort.
* **Monitor endpoints for threats:** Gain experience in endpoint detection and response (EDR) and log analysis.
* **Utilize SIEM tools to handle incidents:** Master the use of Security Information and Event Management (SIEM) systems for log aggregation and correlation.
* **Investigate forensic artifacts:** Develop skills in digital forensics using tools like Autopsy.

## My Experience

As an aspiring SOC analyst, I was naturally excited to complete TryHackMe's dedicated training for the role. The course provided a comprehensive overview of various industry tools and frameworks, offering valuable hands-on experience.

I particularly enjoyed working with familiar tools like SIEMs, Wireshark, and Snort. However, the path also introduced me to new and powerful tools such as:

* **Autopsy:** For forensic analysis of disk images.
* **Zeek (formerly Bro):** For network traffic analysis and intrusion detection.
* **OSquery:** For querying operating system data.

This exposure to a wide range of tools significantly broadened my understanding of SOC operations and incident response.
